# Проверка контекста qwen3.6:27b на GPU-сервере

Дата: 2026-09-12. Модель: `qwen3.6:27b`, Q4_K_M. Ollama: 0.33.1.
Драйвер NVIDIA: 595.91.07. На каждом значении выполнено по два
последовательных запроса с русской стенограммой длиной 40 189 символов
(`prompt_eval_count=11067`). GPU проверялись строго по очереди.

Загрузка модели занимала 7.1–7.9 с на RTX 4090 и 7.5–8.2 с на RTX 3090.
Обработка 11067 входных токенов занимала около 5.05 с на RTX 4090 и
9.65–9.80 с на RTX 3090. Скорость генерации составляла примерно 37 токенов/с
и 32–33 токена/с соответственно. Повторный запрос с кэшированным префиксом
занимал 3.0–3.5 с. Исключение — `num_ctx=100000` на RTX 4090: из-за переноса
5% модели на CPU первый запрос замедлился до 19.52 с.

После каждого замера модель выгружалась через `keep_alive: 0`; VRAM
возвращалась к 545 МиБ на RTX 4090 и 394 МиБ на RTX 3090. После выгрузки Qwen
Whisper `large-v3` успешно выполнил короткую транскрипцию на каждой карте
(HTTP 200), а затем освободил память. Ошибок CUDA OOM в журналах нет.

Контрольная последовательность через диспетчер `Qwen -> Whisper -> Qwen`
прошла на одном слоте с HTTP 200 на каждом шаге. Запрос Qwen с
`num_ctx=65536` принят без `gpu_request_not_supported`.

## Применённые значения

- `GPU_DEFAULT_MAX_CONTEXT_TOKENS=65536`;
- RTX 4090, `gpu-1`: `max_context_tokens=69632`;
- RTX 3090, `gpu-2`: `max_context_tokens=73728`;
- IZ.Scribe: `LLM_TEXT_CONTEXT_TOKENS=65536`.

Лимиты привязаны к текущей модели, версии Ollama и установленным картам.
После замены GPU измерения необходимо повторить.
